# Sign Language Detection using YOLOv8

## Overview
Real-time sign language recognition using YOLOv8 and OpenCV.

## Tech Stack
- Python
- YOLOv8
- OpenCV
- Raspberry Pi (Future Deployment)

## Features
- Real-time hand gesture detection
- Alphabet recognition
- Sentence formation (Prototype)

## Future Improvements
- Cloud deployment
- ESP32 camera integration
- Improved dataset
